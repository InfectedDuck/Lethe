# Whisper

One line in the `interface` style and `fog` colour, centred `space-4` above the bottom edge. It is how the garden tells the person something, and it fades in and then out.

**Provide** the sentence as children. Set `visible={false}` to let it fade out over 2.4s. Show at most one whisper at a time.

- Speak about memories, not the app: "The lake house is drifting into fog." Never use "warning", "error", "you haven't…", streaks or counts.
- When something still holds a fading memory, name it ("Mira still holds it."), so that fading reads as an invitation.
- Hide it after 6s or on the next pointer movement. It is announced politely to assistive tech.

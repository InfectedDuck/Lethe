# Button

The one button: a lowercase word in the `interface` style, either text-only or inside a thin 1px outline pill, in `fog` that brightens to `text-primary` on hover and focus.

**Provide** the word as children and an `onClick`. Set `variant="pill"` for the one main action in a group, such as tend or plant. Everything else is text-only.

- Never use a solid fill, an icon, or a badge.
- Space buttons `space-3` apart in a row.
- Use verbs from the garden: tend, plant, let go, return.
- Letting go is never shown as destructive: no red and no confirmation. The memory drifts to lost and can still be returned to.
